# Customer Relationship Management (CRM) System - Frontend

## Overview
This repository contains the frontend code for the Customer Relationship Management (CRM) system. The frontend is built using React, TypeScript, and Tailwind CSS, providing a modern and responsive user interface for managing customer and product information.

## Technologies
- React
- TypeScript
- Tailwind CSS
- Jest
- Puppeteer

## Features
- **Modern UI:** Built with React and Tailwind CSS for a responsive and intuitive user experience.
- **Type Safety:** Utilizes TypeScript for improved code quality and maintainability.
- **Image Upload:** Integrates with AWS S3 for secure and efficient image storage.
- **Comprehensive Testing:** Uses Jest and Puppeteer for end-to-end testing to ensure frontend functionality and user interactions.

## Installation

1. Clone the repository:
```bash
  git clone https://github.com/IzzySato/crm2_client.git
  cd crm2_client
```

2. Dependencies:
```bash
  npm install
```

3. Set up environment variables
API_URL=http://localhost:8080
JWT_TOKEN_SECRET=jwt

4. Run the application
```bash
npm start
```

5. Testing
```bash
npm test
```
